# 反向木鱼（开源本地版）

> 电子积德，赛博回向。点击木鱼，为讨厌的人积累业力。

## 项目简介

反向木鱼是一个纯前端单页面 Web 应用。用户可以添加"制裁对象"（如老板、同事），点击木鱼为其积累"业力值"。所有数据保存在浏览器 localStorage 中，无需服务器即可运行。

整体风格融合禅意与暗黑元素，带有戏谑的仪式感。

## 功能特性

- **对象管理**：添加、删除制裁对象，列表按业力值降序排列
- **木鱼敲击**：点击大木鱼为选中对象增加业力，附带震动、涟漪、飘字等动效
- **木鱼音效**：敲击时播放真实的木鱼音效
- **数据持久化**：所有数据保存在浏览器 localStorage，刷新页面不丢失
- **响应式布局**：支持手机端访问

## 技术栈

- 前端：原生 HTML + CSS + JavaScript（单文件应用）
- 数据存储：浏览器 localStorage
- 无需后端、无需数据库、无需服务器

## 使用方法

### 方式一：直接打开（最简单）

1. 下载本项目的 `index.html` 和 `media/muyu.mp3`
2. 确保 `media/muyu.mp3` 与 `index.html` 在同一目录下
3. 双击 `index.html` 用浏览器打开即可使用

### 方式二：本地静态服务器（推荐）

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx serve .

# 然后浏览器访问 http://localhost:8080
```

## 文件结构

```
.

```

## 注意事项

- 数据仅保存在当前浏览器的 localStorage 中，清除浏览器数据会导致数据丢失
- 不同浏览器、不同设备之间的数据不互通
- 如需多设备同步和云端存储，请参考本项目的完整服务端版本
